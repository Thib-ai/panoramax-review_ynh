# Panoramax Review

Review street-level imagery from [Panoramax](https://panoramax.mapcomplete.org). Import pictures from any Panoramax instance, review them (OK / error with reason), track flagged issues in a dashboard, and export reviews as CSV, GeoJSON, or JSON.

**Features:**
- Import pictures by UUID or by fetching from any Panoramax API instance
- Review images with thumbs up/down and error categorization (blurry, dark, wrong location, etc.)
- Dashboard with filters, search, and batch operations
- CSV / GeoJSON / JSON export
- Offline queue with sync
- PWA with service worker and image caching
- Single-user with YunoHost SSO authentication
